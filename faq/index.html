FAQ

常见问题

关于研究、项目与合作。

以下回答反映当前可核验的公开资料；研究方向不等于已交付的产品能力。

01勘境是什么？

勘境智能（KineWorld）围绕动作条件世界模型、预测表征、规划与控制开展研究。

02什么是世界模型？

可以把它理解为一个帮助系统推测环境如何变化的内部模型：在给定当前观测和可能动作时，尝试预测后续状态。

03勘境和大语言模型有什么区别？

勘境关注动作、环境变化与未来推演；语言模型主要处理语言信息。两者可以互补，但研究问题不同。

04世界模型为什么和机器人有关？

机器人需要根据动作可能造成的后果选择下一步。世界模型可为这种预测与规划提供研究路径。

05勘境目前有商业产品吗？

目前公开资料未核验可对外承诺的商业产品。网站展示的是研究与工程项目。

06哪里看代码与研究进展？

请访问勘境 GitHub 组织、项目仓库及本网站进展页。

07如何参与开源贡献？

先阅读目标仓库的 README、许可证和贡献说明，再通过 Issue 或 Pull Request 交流。

08如何进行研究合作？

可通过相关公开仓库的 Issue 提出具体研究问题、复现结果或合作方向。

09如何联系勘境？

目前公开核验的渠道是 GitHub 组织。公司邮箱等渠道核验后会在联系页统一公布。

10KineWorld 和勘境是什么关系？

KineWorld 是勘境的英文品牌名。
